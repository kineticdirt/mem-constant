# Character portraits

Put portrait files here (`png` / `jpg` / `webp` / `gif` / `svg`), then set each character’s **Image path** in the Linuxbox dashboard **Chars** tab.

Example:

1. Add `cassidy.webp` in this folder.
2. On `/Linuxbox/` → **Chars** → Cassidy → Image path: `characters/portraits/cassidy.webp`
3. Save — the roster tile and sheet use `/api/characters-registry/image`.

Path is relative to `campaigns/tropic-gooner/`. No file → initials placeholder.
