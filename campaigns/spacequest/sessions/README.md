# Sessions — table organization

**Purpose:** Per-session **prep**, **battle assets**, and **run order** live under `sessions/session-NN/`. Campaign-wide **arc**, **station canon**, and **mechanics** stay in [[../story/README]].

## Index

| Session | Folder | Narrative writeup | Notes |
|--------|--------|-------------------|--------|
| **1** — Docking bay & asteroid mouth | [[session-01/README]] | [[../story/session-01-docking-bay]] | Maps, VTT, Session 1 only |

Add **`session-02/`** (etc.) here when you create the folder; keep the same pattern: **README** as entry point, subfolders only when needed (e.g. `maps/`).

## What goes where

| Content | Location |
|---------|----------|
| **Beats, clues, safety, time blocks** | `story/session-NN-*.md` (story spine) |
| **Run checklist, opening flow, GM-only beat order** | `sessions/session-NN/session-*-beat-plan.md` or similar |
| **Grids, SVGs, VTT, tokens** | `sessions/session-NN/maps/` |
| **Party tier, Tension, gunplay** | [[../story/systems-dnd5e-lewd-tech]] (campaign-wide) |
