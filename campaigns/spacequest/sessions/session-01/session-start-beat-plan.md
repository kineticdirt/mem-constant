# Session start — beat plan (dock → corridor → reception)

**Canon session writeup:** [[../../story/session-01-docking-bay]] · **Maps:** [[maps/README]] · **Lore pins:** [[maps/lore-placements]] · **Gunplay:** [[../../story/systems-dnd5e-lewd-tech]] §3.0–3.1.2

This note is a **GM-facing skeleton**: opening flow, **three main areas**, concrete turret ammo default, and **what to flesh out** next. It does not replace the long-form session doc.

---

## Opening flow (table order)

1. **Approach** — Party is already on the **contractor ship**; establish who is on the bridge, who is geared for EVA, tone. *Optional:* one ship-side complication (sensor ghost, docking clamp, Cherish clearing an alert).
2. **Berth & mag field** — Bay seals / mag barrier; PA or HUD: unauthorized vessel, lethal force. First **foot on deck or gantry** can trigger targeting overlay.
3. **Beat A — “Mostly empty” turrets** — Emplacements **track and fire**, but each has only **~5–6 effective kinetic rounds** left in the hopper, then **dry fire**, grind, relay chatter. Comedy + unease; not a war of attrition.
4. **Cross the dock** — Cranes / mine strip / cover movement (per map). Pick up **wrong-ammo** or **log** clues if you want.
5. **Inner airlock + connector** — Rush vs slow; contrast **noise → cleanliness**.
6. **Beat B — Reception** — Staged bodies, desk, frozen month clock; investigation; optional cliff toward Session 2.

---

## Turret ammo default (5–6 rounds each)

**Fiction:** Hoppers were **starved** before the party arrived—logistics failure, sabotage, or something **pulling** resources elsewhere. Each emplacement (**T1–T4**) still has **enough pride to kill** but not enough **brass** to last.

**At the table (keep it simple):**

- **Per turret:** **5 or 6** “shots” maximum before **dry fire** for that gun. You can treat one **burst** (overlay §3.1) as **one** or **two** shots toward that budget—pick one and stay consistent for the fight.
- **After the budget:** no more kinetic from that emplacement until **resupplied** (unlikely here); audio **click-click**, servo hunt, optional **single** capacitor pop (§3 Beat A option 2) if you want one hazard spike.
- **Vertical:** Z1 gantries can add **one** sniper or empty catwalks—same “almost out” vibe if you give a **magazine** of 5–6 for a guard.

Do **not** track individual bullets unless the table enjoys it; the **feel** is *almost empty*, not simulationist.

## Fleshing-out checklist (key details & descriptions)

Use this as a punch list; tick or expand in your prep notes.

### Area 1 — Dock & berth

| Topic | Detail to decide or write |
| ----- | --------------------------- |
| **Arrival moment** | Exact trigger: first boot on gantry vs first airlock cycle vs mag field stable. |
| **Which turrets shoot first** | T1+T3 vs all four stutter; warning burst vs panicked full-auto until empty. |
| **5–6 rounds** | Confirm burst = 1 or 2 “ticks” off the 5–6 budget (see above). |
| **Sound/light** | One paragraph read-aloud: servos, tracers, lasers dying mid-sweep ([[maps/docking-bay-z0-deck]] atmosphere). |
| **Cranes & crates** | Which crane shows **wrong ammo** (#4 vs #5 red herring). |
| **Mine strip** | Armed / dud / one pop — [[../../story/session-01-docking-bay]] Beat A option 3. |
| **PC hooks** | Who tanks attention, who hacks a kiosk, who drags someone to **H** hull cover. |

### Area 2 — Airlock + connector

| Topic | Detail to decide or write |
| ----- | --------------------------- |
| **Bioscan** | False positive, dead screen, or fake “welcome home” (IT ghost teaser). |
| **Corridor** | One **sensory** line: smell, temperature, “showroom” floor (**#8**). |
| **Time** | How long you want this beat—30 seconds of play or a full paranoia beat. |
| **Clue** | Whether you **foreshadow** lobby (distant power hum, scrubber tick). |
