# Agent reports — SpaceQuest (Space Base V2)

Reports written by the agent after reading the campaign corpus (`story/`, `lore/`,
`characters/`, `discord-export/` analyses). These are **drafts for human review** —
per `characters/meta/LOCAL-LLM-NOTES.md`, model output is a draft; the table keeps canon.

## Method

- **Evidence-anchored:** claims point at a source file (and, where possible, the
  Discord export path / line) rather than inventing new prose. Matches the
  "analysis docs point at export paths, not forked prose" rule in
  `reference/timeline-and-analysis-pipeline-plan.md`.
- **VTT/maps excluded:** map and VTT material was intentionally left out of this
  repo copy; reports do not depend on it.
- **Two clocks kept separate:** *played* canon (what the Discord `#rp` export
  actually contains) vs *designed-ahead* canon (asteroid blacksite / Amalgam
  design docs that are still ahead of play).
