## 1. Session-zero agenda (30–45 min, voice)

1. **Pitch (2 min).** Read the Setup paragraph from the handout out loud. Stop there. If they want more, they ask.
2. **Lines & veils (5–10 min).** This setting has vice, debt, family violence, and the Below. Collect lines (never on screen) and veils (fade to black) in `#dm-screen` before Session 1. Default veil: on-screen torture. Default line: whatever the table adds.
3. **Crew build (15–20 min).** Each player, in turn:
   - Name, ancestry, class concept → pick a **crew seat** (handout §Crew Roles; doubling a seat is allowed if the players can explain how it works).
   - **One bond:** "I trust ___ with the bag because ___." Another player's name in the blank.
   - **One debt:** someone outside the crew the PC owes — money, blood, or a promise. The GM writes these down. They are all load-bearing.
4. **The note (5 min).** Read Rosa's note. Tell them the crew hit a Valenti counting room two weeks ago and didn't know. Let them react in character if they want. This is the campaign's first scene — it just happens to be a conversation.
5. **Scheduling.** Session 1 date poll in `#rolly-poley`. Target: 90–150 minutes, one job, one night.
