# Archive

Use when a Discord user runs `/skill archive` (or asks to save/dump/archive the current clarification).

## Do
1. Summarize the useful beat from recent chat (rules clarifications, lore facts established, logistics).
2. Write a short markdown note under:
   `~/agent-dump/campaigns/nyc-mafia-dnd/notes/discord-archive/`
   Filename: `YYYY-MM-DD-HHMM-<slug>.md` (UTC).
3. Include: date, channel if known, who asked, 5e vs NYC-homebrew tags, bullet facts.
4. Confirm the path back in Discord (one short message).

## Do not
- Archive Session-1 spoilers, ledger twists, Below access maps, Bone Index, or GM-only LOCKS.
- Overwrite existing notes; always create a new file.
- Dump full channel history — keep it a short archive note (roughly ≤40 lines).
