# Borough vs ward grain — canon stroke (G-1)

**Chosen fork: B — Wards first; boroughs are shorthand only.**

## The rule

There is **no separate borough layer** in SoT. The five borough names are period geography for non-NYC readers; play treats them as flavor labels over the ward/neighborhood map that already exists. **Culture** sounds 1950s–1960s (jazz, vice, Jersey commute); **travel kit** is late-1800s (ferry steam, tube exchanges, warded carriages).

| What this means | In play |
|----------------|---------|
| **Travel beats** | Route by ward: Red Hook to Harlem = ferry + uptown train; "crossing into Brooklyn" is color only, not a structural beat |
| **Heat / heat ledgers** | Track by ward or precinct, not by borough. "Brooklyn heat" is shorthand for whichever ward cluster generated it |
| **Family territory** | Read "home borough" as **home ward cluster** (see G-2). Valenti = Red Hook + Gowanus docks; Moretti = Little Italy + LES; Chen-Okafor = Flushing–Jamaica (+ Chinatown franchise); Kowalski = Staten + Jersey haul mouths; Ashford = Midtown polite-denial doors |
| **Commission language** | When the Commission says "Brooklyn," they mean the family's cluster of wards, not a political line. Translate any borough-named deed to its ward cluster |
| **Vice geography** | Jazz clubs and licensed salons are **ward-typed**: open on docks/Harlem edges; polite denial in Midtown Blue Note fronts |

## What stays the same

- **Ward-tiered visibility** (open / licensed veil / polite denial) — unchanged (B2/C2).
- **Family-home map** — G-2 canon clusters; soft edges.
- **Play reports** — use `2026-08-01-*.md`; pre-08-01 files are superseded.
- **Q2 (hard cores, soft edges)** — applies to **ward clusters**, not borough lines. See G-2.

## Implications for Phase G onward

1. **G-2 and G-3** — rewrite "borough" stakes as **ward cluster** stakes. "Cross-borough jobs" become "cross-cluster" or "cross-ward jobs" where travel matters.
2. **G-4 borough flesh** — focus on **ward-specific keyed spots** under each borough's umbrella, not borough-level sheets.
3. **G-12 draft order** — P1 order still works as a drafting sequence of ward clusters (Brooklyn docks cluster first → Manhattan wards → Queens wards → Staten → Bronx).
4. **Table-facing text** — use "Brooklyn/Queens/…" as plain English; no need to invent a NYC-native-isms glossary. Players will say "I'm in Brooklyn" and that's fine — the SoT knows it's Red Hook.
